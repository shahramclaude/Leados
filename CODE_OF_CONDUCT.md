# Code of Conduct

LEADOS is a small, young project. Until it has a dedicated conduct committee, this short policy
applies to all project spaces (issues, pull requests, discussions).

## Expected behavior

- Be direct about problems with the code or docs; be respectful toward the people who wrote them.
- Prefer a reproduction, a failing test, or a concrete file/line reference over a general
  complaint.
- Assume good faith. Most bugs are mistakes, not malice.

## Unacceptable behavior

- Personal attacks, harassment, or discriminatory language or jokes.
- Publishing others' private information without consent.
- Sustained disruption of issues, PRs, or discussions.

## Enforcement

Report concerns by opening a private security advisory on the GitHub repository (preferred for
anything sensitive) or by flagging a maintainer directly in an issue. Maintainers may edit,
remove, or lock content, and may temporarily or permanently ban anyone whose behavior is
inconsistent with this policy.

## Scope

This applies to all LEADOS project spaces and to representing the project in public spaces.

This document is intentionally short. If the project grows a dedicated governance team, this file
should be replaced with a full Contributor Covenant and the change should be recorded in
`CHANGELOG.md` and linked from `docs/adr/`.
