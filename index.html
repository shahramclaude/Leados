Provenance — read before trusting anything else on this page

Verified first-hand this session (via GitHub's REST API + raw file fetches, not the task prompt's own framing):

  • V1. github.com/wbweve/Leados contains two structurally different deliveries: ~60 loose root-level .tsx/.md files (including a standalone vanilla-JS index.html, confirmed via the repo's git tree) plus a separate, live src/ Vite+React+TypeScript app.
  • V2. The repo's own AI-SESSION-LOG.md (read directly, raw) documents a prior session that verified src/lib/infoTheory.ts is real and wired into a live Thermodynamics.tsx → IntelligenceView.tsx → App.tsx render chain.
  • V3. That same log documents src/lib/core.ts, intelligence.ts, and physics.ts as present but orphaned/broken (intelligence.ts imports { engine, run } from ./core, which does not export them).
  • V4. No file, export, or identifier resembling a CAS engine, risk register, inference engine, leadership-science library, self-calibration module, universal protocol, or decision-tree engine was found anywhere in that repo's documented inspection.
  • V5. Therefore: this task's pasted "Part 3–6 / pt-M" brief (leadership science library, self-calibrating rules, universal protocol, decision trees) is an UNVERIFIED EXTERNAL SPECIFICATION supplied by the task prompt — not a fact about the real repo. This is the same treatment the repo's own prior sessions gave to the earlier "pt-L" brief.

What this delivery actually is: an original, single-file reimplementation of the pt-M brief's described behavior, built because this tool environment only supports a hand-authored index.html (no npm/Vite build step available here). Bugs found in the pasted brief's own pseudocode (duplicate object key in initiative-kill; a self-referential const volatility = volatility ? ... assignment in assessVUCA that would throw a ReferenceError if run as written; calls to undefined LEADOS.correlate/backwardChain/LEADOS.temporalField) were fixed or replaced with disclosed, simplified stand-ins rather than copied verbatim.

Synthetic data: deterministic PRNG (seed 42), 4 directs + 8 skip-level reports, ~120 days of synthetic events, generated on first load and stored in localStorage under leados-pt-m:v1. Use "Regenerate synthetic data" above to rebuild it.

The T_M_*/G_M_* test IDs in the pasted brief could not be verified anywhere either; rather than claiming to "pass" tests under names whose real bodies are unknown, this build ships its own originally-named self-check (see console on load, prefixed [pt-M self-test]) exercising this file's own logic.
