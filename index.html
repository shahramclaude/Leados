What this build is

This index.html does not fork, copy, or continue any code from wbweve/Leados or from the pasted spec. It reuses the pasted spec's CSS token structure (surface stack / ink stack / severity hues / domain hues) as a generic design system — original styling, not a provenance claim — and otherwise implements a small, original findings/risk/health-wall sandbox from scratch, built for this tool environment's single-file HTML/Tailwind/vanilla-JS constraint.
