## Summary

- **26 independently sourced discrepancies** (requirement: ≥ 20).
- **5 of the 26 (F3, F4, F5, F6, F7) falsify the subject repository's own prior "Part 00"/"Part 19"
  audit documents**, not just the README — this is the strongest evidence for why `docs/EVIDENCE-LEDGER.md`
  and `scripts/ledger-lint.mjs` must be an automated, machine-checked gate rather than narrative
  self-report: narrative self-report has already failed, more than once, in this exact repository.
- Root cause pattern: every prior session narrates "I checked, nothing was found" as prose. None of
  those checks were re-run by a later session before new claims were layered on top. The fix is
  structural (Phase 3: `ledger-lint.mjs` + `npm run verify`), not a one-time cleanup.
