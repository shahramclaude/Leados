# Reference: configuration

Generated by grepping actual `process.env` reads and config files in this repository — there is no
separate config-loading framework.

| Variable | Required | Read in | Purpose |
|---|---|---|---|
| `DATABASE_URL` | Yes | `src/db/index.ts:4` | PostgreSQL connection string for the `pg.Pool` used by Drizzle. Throws at import time if unset. |
| `NODE_ENV` | No (set by tooling) | `src/db/index.ts:20` | When not `"production"`, the DB pool is cached on `globalThis` to survive Next.js dev hot-reloads. |

## Files that configure the system (non-env)

| File | Purpose |
|---|---|
| `.env` | Local `DATABASE_URL`. Not committed with real secrets in this template; replace for your environment. |
| `drizzle.config.json` | Drizzle Kit config: dialect, schema path (`./src/db/schema.ts`), and `dbCredentials.url` used by `npx drizzle-kit push`. **Note:** this file's `dbCredentials.url` is independent of `.env`'s `DATABASE_URL` — keep them in sync manually, there is no shared source today. |
| `next.config.ts` | Currently empty (`{}`) — no custom Next.js configuration. |
| `tsconfig.json` | Strict TypeScript config, `@/*` path alias to `src/*`. |
| `eslint.config.mjs` | Flat ESLint config extending `eslint-config-next/core-web-vitals`. |

## There is no `NEXT_PUBLIC_*` variable in use

No client-exposed environment variables exist in this codebase today — everything that touches
`process.env` runs server-side (API routes, the server-component dashboard page, and `scripts/seed.ts`).
