## Blunt current-state assessment before this change

- The root `index.html` + `app/**` path is an unusually broad, working local-first leadership workspace. Its versioned normalizer, atomic one-blob writes, audit events, deterministic domain engines, generalized post-commit rules and large Node/JSDOM test suite are real implementation, not a deck.
- It is **not** collaborative SaaS: no account/tenant service, server durability, employee self-service, independent source attestation, or durable cross-tab compare-and-swap was verified. Multi-user product claims are not supported by this checkout.
- The Impact Ledger has pre-registration dates, dated reconstructions, counterfactual checks, denominator-aware per-person rates in the calculation, and an immutable saved result. But the pre-change evidence format did not preserve those per-person denominators, and an editable source record could later change without the locked card warning the leader. Its interrupted-time-series design remains observational and does not establish causality.
- UI automation is JSDOM+axe, not a real browser or assistive-technology session. Actual rendered contrast, screen-reader output, representative team use, effect on leadership outcomes, and quarantined legacy behavior remain **[UNVERIFIED]**.

## Highest-leverage gap selected

A new terminal would have expanded an already crowded product. The higher-leverage move was to make the existing prospective-evaluation instrument answer an uncomfortable question: *does the current workspace still contain the evidence from which this immutable score was produced?* Add denominator provenance, detect reconstruction drift at the score's original date, remove changed vintages from calibration/confirmatory counts, and route a human-confirmed drift through the existing event-driven automation spine.

## Remaining hard gaps

1. Per-person denominator snapshots still do not describe randomized treatment assignment/exposure or a concurrent control.
2. A deterministic comparison is a local change detector, not a cryptographic signature, external audit, or proof about who edited a record.
3. Only three rate vitals currently carry event numerator and active-roster denominator; this is not a universal source-lineage protocol.
4. No real-browser, screen-reader, field-outcome, competitor-trial, large-workspace performance, or legacy-app behavioral audit was performed.
5. Workspace-wide localStorage writes can still race across tabs; cross-tab transactional durability remains open.
