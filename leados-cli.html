LeadOS CLI (pt-M) — original companion file, connects to index.html via BroadcastChannel("leados-protocol-v1"). Type 'help' for commands. index.html must be open in another tab on the SAME ORIGIN. Known limitation (disclosed): if both files are opened as local file:// documents, most browsers give each file its own opaque origin, so BroadcastChannel messages may silently never arrive. Serve both files from one local HTTP server (e.g. `python3 -m http.server`) for this to work reliably. >
